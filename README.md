# OpenMOSS website — legacy source

This repository contains an earlier version of the OpenMOSS website, with pages for people, projects, positions, and resources.

**Visit the current website at [openmoss.ai](https://openmoss.ai/).** Current website source and updates are maintained in [OpenMOSS/OpenMOSS.github.io](https://github.com/OpenMOSS/OpenMOSS.github.io).

## Repository contents

- [`index.html`](index.html): website entry point
- [`people.html`](people.html) and [`alumni.html`](alumni.html): team pages
- [`projects.html`](projects.html): project directory
- [`positions.html`](positions.html): positions page
- [`resources.html`](resources.html): resource directory
- [`assets/`](assets/): shared website assets

For current research projects and model downloads, browse [OpenMOSS on GitHub](https://github.com/OpenMOSS) and [Hugging Face](https://huggingface.co/OpenMOSS-Team).
